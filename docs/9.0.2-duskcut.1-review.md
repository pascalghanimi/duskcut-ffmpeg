## Review performed

- Source package contains both byte-identical original source parts, the exact
  recipe snapshot, executed configuration/patches/logs and post-build runtime
  license evidence. It is not just links to upstream repositories.
- Independent archive review checked 249 used input blobs, 41 selected dependency
  archives, 32 recipe files, 172 evidence files and the matching runtime review.
- Runtime ZIP members and both original executable hashes were independently
  checked against the completed build. Locally assembled and downloaded release
  archives are byte-identical.
- Native baseline/candidate compatibility matrix: 90 checks passed, including
  running only the two executables with an empty developer PATH. NVIDIA encode
  and decode were exercised on the available machine.
- Focused editor integration: 28 tests passed, including actual media probing,
  decoding and export consumers and a synthetic 200-cut audio export.
- GCC runtime evidence includes the actual linked `libatomic` archive, its
  GPL license and GCC Runtime Library Exception. The source archive keeps this
  additional review separate from the unchanged compilation input lock.

## Use and limits

Download the runtime and corresponding-source archive from this versioned
release. Follow the source TAR's README for replay instructions on a Linux
Docker host. Compilation uses the fixed compiler image with networking disabled.
The source archive includes the pinned image identity and toolchain recipe;
the compiler image is a separately obtained general build tool.

`ffmpeg-release.candidate.json` preserves the original assembler output. Its
candidate flag intentionally prevents automatic editor activation. The editor
selects a separately reviewed, approved pin after this release review.

The checks do not certify every Windows version, GPU, media file, UI playback
path, signed installer, or bit-for-bit reproducibility on arbitrary hosts.
Intel and AMD acceleration were unavailable on the test machine for both the
previous and new runtime. Source/license review is not a blanket legal or
patent guarantee. This release does not fix missing corresponding-source
evidence for historical Gyan-based DuskCut installers.

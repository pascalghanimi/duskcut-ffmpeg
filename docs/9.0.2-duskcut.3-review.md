## Functional evidence and limits

Against the tools extracted from the ZIP, 12 focused application suites passed:
87 tests passed, one optional user-file test was skipped. These include real
Windows H.264/AAC import preflight, unsupported camera-profile rejection,
missing HEVC-extension classification, export metadata, cancellation/atomic
publication, generated-media ledger, PNG/JPEG/GIF output and snapshot handling.
Only synthetic media was used; no paid/provider requests occurred.

A separate native reference-comparison harness passed 15 H.264/AAC/profile/
seek checks. Four HEVC decode comparisons did not pass because this test
account has no HEVC MFT; they are not claimed as successful HEVC playback.
The application correctly identified the missing extension. This is not a
full application/GPU/driver matrix, HEVC-enabled-host verification or signed
installer test. Older colour tests that require excluded software codecs as
fixture encoders are not counted as passing compatibility tests.

Before publishing an editor installer, inspect its actual bundled executable
hashes (allowing only an independently verified Authenticode addition), source
links, licences and application smoke tests. Source availability is not proof
of the contents of a not-yet-built installer.
